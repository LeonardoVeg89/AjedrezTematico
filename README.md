# AjedrezTematico

Este repositorio contiene modelos y texturas para un proyecto de ajedrez temático en OpenGL.

## Estructura de carpetas

- `Modelos/`: Contiene los archivos `.obj` y `.mtl` de las piezas del ajedrez.
- `Texturas/`: Contiene las imágenes asociadas para texturizar los modelos.

## Cómo trabajar con los archivos

1. Al momento de descargar cada archivo (exceptuando los de blender) e implementarlo en Visual Studio debe colocarse los archivos de modelo y sus texturas en la misma carpeta para que funcionen correctamente.

---

## Recomendaciones

- Mantener organizadas las carpetas.
